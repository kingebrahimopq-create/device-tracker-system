# 🚀 دليل تشغيل الخادم الدائم والمشفر (Permanent & Secure Hosting)

لضمان عمل نظام تتبع الأجهزة بشكل دائم وبدون انقطاع، يوصى بالابتعاد عن بيئات التطوير المؤقتة مثل Replit واستخدام منصات استضافة سحابية احترافية تدعم التشفير (HTTPS) بشكل تلقائي.

---

## 🛠️ الخيارات الموصى بها للاستضافة الدائمة

| المنصة | الميزات | التكلفة |
| :--- | :--- | :--- |
| **Railway.app** | سهولة فائقة، دعم Docker، تشفير HTTPS تلقائي | مجانية (بحدود) / رخيصة |
| **Render.com** | دعم كامل لـ Node.js، واجهة بسيطة | مجانية (للمشاريع الصغيرة) |
| **DigitalOcean** | تحكم كامل، استقرار عالي جداً | تبدأ من 5$ شهرياً |

---

## 📦 خطوات التشغيل باستخدام Railway (الأسرع والأكثر استقراراً)

1. **قم بربط حساب GitHub الخاص بك** بـ [Railway.app](https://railway.app).
2. اختر **"New Project"** ثم **"Deploy from GitHub repo"**.
3. اختر مستودع `device-tracker-system`.
4. انتقل إلى إعدادات الخدمة (Service Settings) في Railway:
   - تأكد من تعيين `Root Directory` إلى `/server`.
   - سيقوم Railway تلقائياً باكتشاف `Dockerfile` الذي قمت بإضافته وبدء عملية البناء.
5. بمجرد انتهاء البناء، سيعطيك Railway رابطاً مشفراً (مثل: `https://your-app.up.railway.app`).
6. **هام:** قم بنسخ هذا الرابط ووضعه في إعدادات تطبيق `hidden-apk` وتطبيق `controller-app`.

---

## 🔐 لماذا هذا الخيار أفضل؟

1. **تشفير HTTPS دائم:** جميع البيانات المرسلة والمستقبلة ستكون مشفرة عبر بروتوكول SSL/TLS.
2. **تشغيل 24/7:** لن يتوقف الخادم كما يحدث في Replit عند إغلاق المتصفح.
3. **إعادة التشغيل التلقائي:** في حال حدوث أي خطأ، ستقوم المنصة بإعادة تشغيل الخادم تلقائياً.
4. **حماية البيانات:** استخدام Docker يضمن عزل الخادم وحمايته.

---

## ⚠️ تنبيهات هامة
- لا تنسَ تحديث رابط الخادم في التطبيقات بعد الحصول على الرابط الجديد.
- يمكنك استخدام ملف `.env` في Railway لإضافة متغيرات بيئية سرية إذا لزم الأمر.
